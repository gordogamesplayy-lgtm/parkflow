Importar Planilhas Antigas (Excel)

Carregue suas planilhas de leilão antigas salvas em formato CSV (separado por ponto e vírgula ";") diretamente na aba Embarcados

Instruções importantes para Importação de Planilhas:
  1. Abra sua planilha antiga no Excel, vá em Salvar Como e escolha a opção CSV (separado por ponto e vírgula) (*.csv).
  2. O cabeçalho deve conter exatamente as colunas na ordem ou nomes correspondentes (ex: PLACA, MODELO, VALOR TRANSI, VALOR ES, DESPESAS EXTRAS, ORIGEM, DESTINO, PRIMEIRA ESTADIA, ÚLTIMA ESTADIA).
  3. Campos financeiros vazios serão assumidos como R$ 0,00 automaticamente.

Sincronização em Nuvem (Supabase)

Conecte seu sistema a um banco de dados online gratuito para sincronizar o computador e o celular em tempo real

Desconectado (Dados Locais)
Encontrado em Project Settings > API
Encontrado em Project Settings > API > anon public

Antes de conectar, você deve criar as tabelas no seu banco Supabase. Copie o script SQL abaixo, acesse o painel do seu Supabase, clique em SQL Editor ➡️ New Query, cole o script e clique em Run. 

-- 1. Veículos Ativos no Pátio
CREATE TABLE IF NOT EXISTS active_yards (
    id TEXT PRIMARY KEY,
    plate TEXT NOT NULL,
    model TEXT NOT NULL,
    yard TEXT NOT NULL,
    bank TEXT,
    "entryTime" TEXT
);

-- 2. Histórico de Saídas Comuns
CREATE TABLE IF NOT EXISTS history_yards (
    id TEXT PRIMARY KEY,
    plate TEXT NOT NULL,
    model TEXT NOT NULL,
    yard TEXT NOT NULL,
    bank TEXT,
    "entryTime" TEXT,
    "exitTime" TEXT,
    duration TEXT
);

-- 3. Fechamento Leilão (Lote Ativo)
CREATE TABLE IF NOT EXISTS auction_history (
    id TEXT PRIMARY KEY,
    plate TEXT NOT NULL,
    model TEXT NOT NULL,
    "valorTransi" NUMERIC DEFAULT 0,
    "valorEs" NUMERIC DEFAULT 0,
    "despesasExtras" NUMERIC DEFAULT 0,
    "valorTotal" NUMERIC DEFAULT 0,
    yard TEXT,
    origem TEXT,
    destino TEXT,
    "entryTime" TEXT,
    "exitTime" TEXT,
    diarias INTEGER DEFAULT 0,
    "totalEstadias" NUMERIC DEFAULT 0,
    bank TEXT
);

-- 4. Embarcados Leilão (Histórico Geral)
CREATE TABLE IF NOT EXISTS shipped_history (
    id TEXT PRIMARY KEY,
    plate TEXT NOT NULL,
    model TEXT NOT NULL,
    "valorTransi" NUMERIC DEFAULT 0,
    "valorEs" NUMERIC DEFAULT 0,
    "despesasExtras" NUMERIC DEFAULT 0,
    "valorTotal" NUMERIC DEFAULT 0,
    yard TEXT,
    origem TEXT,
    destino TEXT,
    "entryTime" TEXT,
    "exitTime" TEXT,
    diarias INTEGER DEFAULT 0,
    "totalEstadias" NUMERIC DEFAULT 0,
    bank TEXT
);

-- 5. Bancos Cadastrados
CREATE TABLE IF NOT EXISTS registered_banks (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT UNIQUE NOT NULL
);

-- 6. Configurações de Vagas
CREATE TABLE IF NOT EXISTS configs_yards (
    id TEXT PRIMARY KEY,
    value INTEGER NOT NULL
);

-- 7. Vistorias Móveis (Checklist)
CREATE TABLE IF NOT EXISTS vehicle_checklists (
    id TEXT PRIMARY KEY,
    placa TEXT NOT NULL,
    marca TEXT,
    modelo TEXT,
    chassi TEXT,
    ano TEXT,
    data TEXT,
    "estadoVeiculo" TEXT,
    "originalDoc" BOOLEAN DEFAULT false,
    "originalKey" BOOLEAN DEFAULT false,
    "spareKey" BOOLEAN DEFAULT false,
    manual BOOLEAN DEFAULT false,
    extinguisher BOOLEAN DEFAULT false,
    triangle BOOLEAN DEFAULT false,
    "wheelWrench" BOOLEAN DEFAULT false,
    jack BOOLEAN DEFAULT false,
    radio BOOLEAN DEFAULT false,
    "cdPlayer" BOOLEAN DEFAULT false,
    multimedia BOOLEAN DEFAULT false,
    "pneuDianteiroDireito" JSONB,
    "pneuDianteiroEsquerdo" JSONB,
    "pneuTraseiroDireito" JSONB,
    "pneuTraseiroEsquerdo" JSONB,
    "estepeTire" JSONB,
    fotos JSONB,
    "cidadeOrigem" TEXT,
    destino TEXT,
    "cidadeDestino" TEXT,
    "dataOrigem" TEXT,
    "dataDestino" TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);
